# 歌词里的英文

一个由开发者提供课程、访客打开即可学习的音乐英语网站。使用 React、TypeScript 和 Vite；访客无需账号。管理员通过 GitHub 仓库权限发布课程。公开课程初始为空，由站长整理好歌曲与学习内容后发布。音频可以链接到官方歌曲页面。

## 本地启动

需要 Node.js 18、20 或 22 及更新版本。

```bash
npm install
npm run dev
```

在浏览器打开终端显示的地址，默认是 <http://127.0.0.1:5173/>。生产构建使用 `npm run build`，构建后可用 `npm run preview` 在本地查看。

## 使用顺序

1. 在首页点「开始学习」，选择一首歌曲课程。
2. 打开官方歌曲页面听歌，返回本站学习歌名表达与明确标注的主题延伸表达。主题延伸表达不宣称出现在歌词中。
3. 在「定期复习」先回忆英文，再显示答案并选择「忘了」「模糊」「会了」。新卡当天可练习。
4. 在「造句练习」抽取 1～3 个表达，写句子并保存。保存后可回看、编辑、删除。
5. 在「外观与备份」可设置个人本地图片并导出或导入自己的复习数据。

## 开发者维护课程

打开网站的 `/#/admin`，输入具体的 GitHub 仓库地址和仅授权该仓库的细粒度访问令牌（Contents 读写权限）。管理页可以新增或删除歌曲、编辑课程导语、逐张编辑表达卡，也可以批量粘贴已有的表达学习笔记。笔记支持逐行“英文表达 — 中文意思”，以及按空行分隔的“英文表达：”“中文意思：”“使用场景：”“英文例句：”“备注：”字段块。批量识别生成草稿卡片；发布前应逐张检查。点击「发布课程」会更新仓库中的 `src/publishedCatalog.json`，触发 GitHub Pages 构建。令牌只存放在当前浏览器标签页的 sessionStorage 中，不会提交到仓库；关闭标签页后需重新输入。管理员在同一标签页重新打开首页时会进入管理页，访客默认看到学习页。

每首歌、每张卡都使用稳定 ID；网站加载新版本时会更新课程文案，并保留访客原有的复习历史与造句。公开课程只放原创讲解、原创例句和可合法发布的素材。若要在站内展示完整歌词、专辑封面或其他受保护内容，先取得相应公开使用授权。

## 发布到 GitHub Pages

1. 建立一个 GitHub 仓库并推送本项目源码。不要上传 `node_modules`、`dist` 或访问令牌。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. `.github/workflows/pages.yml` 会在推送到 `main` 或 `master` 后安装依赖、构建并发布 `dist`。仓库路径会自动写入 Vite 的 `base`。
4. Pages 构建成功后，用仓库的 Pages URL 打开学习站；管理员用同一站点的 `/#/admin` 进入管理页。

旧版的个人歌曲及其笔记仍在当前浏览器里；相应编辑功能保留用于本地草稿，不是访客学习课程的必需步骤。

## 数据说明

课程随网站代码发布。访客的复习历史、造句、个人草稿和所选图片保存在当前浏览器的 IndexedDB 中，不会由本网站上传。清理浏览器网站数据、换浏览器或换设备前，请先导出备份。官方歌曲链接只有在访客主动点击时才会打开。

旧版批量识别入口仍可在本地草稿页面使用：它按笔记格式解析，不会仅凭歌词自动推断词义。

连续选择「会了」后，下次复习分别安排在 1、3、7、14、30 天后；之后继续保持 30 天。「模糊」安排第二天且不升级；「忘了」安排第二天并重置连续答对次数。

本项目是个人学习工具，非 Taylor Swift 官方网站。
